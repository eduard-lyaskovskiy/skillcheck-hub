# SkillCheck Hub

Multi-tenant assessment and reporting platform built with NestJS, TypeScript, PostgreSQL, Redis, MinIO and Python-based report processing.

## Features

- Multi-tenant architecture
- JWT authentication
- Role-based access control
- Assessment builder
- Candidate test sessions
- Background report generation
- Python report processor
- MinIO/S3-compatible file storage
- Realtime session status with Socket.io
- Dockerized local environment
- Swagger API documentation
